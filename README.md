# Obras Ya

Esqueleto web (v0) — marketplace de oficios en Ushuaia.

## Cómo verlo

```bash
cd ~/Escritorio/obras-ya
python3 -m http.server 5500
```

Abrí http://localhost:5500 en el navegador (o el IP de la VM desde el celu en la misma red).

## Qué incluye este esqueleto

- Catálogo con búsqueda y filtro por rubro
- Perfiles de ejemplo con puntaje y reseñas
- Botón pedir presupuesto (demo)
- Diseño responsive (PC + celular)

## Herramientas en la VM

Para este esqueleto alcanza con: navegador + VS Code + `python3` (ya suele venir).
Git para subir a GitHub. Node/npm solo si más adelante pasamos a React.
